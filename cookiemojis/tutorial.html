Create Emojis - Tutorial

With this Tutorial, you'll learn how to create your own emojis that you can upload to our website.

What You Need

  • Image Editing Software: We recommend Paint.NET. It's free, easy to use, and perfect for pixel art. Of course, you can use other programs as well, but this guide focuses on Paint.NET.
  • Emoji Resolution: The Emojis must be 16:10 Aspect Ratio and preferably 512x320 pixels, but anything larger or smaller will be functional with a limit of 1mb. Download our blank standard template:

Step by Step Tutorial (with Paint.NET)

  1. Open Paint.NET & Load Template: Start Paint.NET. Go to File > Open and select your downloaded template.
  2. Zooming: If you want to zoom in, hold Ctrl and scroll with the mouse wheel.
  3. Designing: Now add images to the template layer or draw your emoji design.
  4. Saving: Go to File > Save As....
    • Make sure to select PNG (*.png) as the file type. Other formats will not work!
    • Give your emoji a name (e.g. my_cool_emoji.png).
    • In the next dialog window, you can keep the default settings. Click "OK".

Important Tips

  • Format: Always save as PNG! Only PNG supports transparency correctly.
  • Transparency: Use it for interesting effects, but don't overdo it. Completely transparent emojis are not visible.
  • Follow the Rules: Make sure your design complies with our rules! No prohibited content.

Upload Emoji

When your emoji is ready, go back to the main page and use the emoji upload assistant to use your masterpiece in Minecraft!
